# Источники и карта обновления

Курс не фиксируется на заранее заданном количестве уроков: новые темы добавляются, когда они нужны для безопасной и практичной разработки.

## Первоисточники

- [Python Tutorial](https://docs.python.org/3/tutorial/) — базовый Python, функции, структуры данных, модули, исключения, классы, форматирование строк и виртуальные окружения.
- [OpenAI Agents documentation](https://developers.openai.com/api/docs/guides/agents) — определения агентов, запуск, оркестрация, guardrails, состояние, интеграции и оценка workflows.
- [Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro) — клиент-серверная модель MCP, инструменты, ресурсы и безопасное подключение внешних систем.
- [LangChain overview](https://docs.langchain.com/oss/python/langchain/overview) — агент как модель + harness, инструменты, сообщения, память, RAG, human-in-the-loop и наблюдаемость.

## Новые темы

- Python для приложений: f-строки, `dataclass`, аннотации типов, `async`/`await`.
- Агентные приложения: конфигурация без секретов в коде, системные инструкции и контекст, структурированный вывод, контракт function calling, RAG.
- Надёжность: лимиты шагов, guardrails, подтверждение внешних действий, трассировка, evals и сценарии отказов.
- Интеграции: MCP и принцип минимальных прав.

В практических заданиях используются локальные имитации API и инструментов, поэтому их можно запускать через Pyodide без ключей и без списания средств.
